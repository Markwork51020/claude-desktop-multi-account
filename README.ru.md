# Claude Multi: мультиаккаунт Claude Desktop, несколько аккаунтов одновременно на Windows

[English](README.md) | **Русский** | [简体中文：Claude Desktop 多开、多账号](README.zh-CN.md)

Claude Multi — бесплатный лаунчер с открытым кодом. Он открывает несколько аккаунтов **настоящего приложения Claude Desktop** рядом друг с другом на Windows: выходить из аккаунта не нужно, и это не веб-обёртка. Каждое окно — полное приложение со своим входом, включая Claude Code и MCP, а ссылка входа из письма открывается в том окне, которое её запросило, а не в основном Claude.

> Неофициальный проект сообщества. Не связан с Anthropic и не поддерживается ею. Claude — товарный знак Anthropic. За соблюдение [условий](https://www.anthropic.com/legal/consumer-terms) для своих аккаунтов отвечаете вы.

> **Про регионы:** Claude Multi не даёт доступа к Claude и не меняет регионы, где сервис работает. Он только запускает официальное приложение, уже установленное на компьютере. Россия сейчас не указана в [списке поддерживаемых регионов](https://www.anthropic.com/supported-countries) Anthropic, поэтому сначала проверьте этот список.

## Подойдёт ли вам

**Подойдёт**, если у вас Windows и Claude Desktop из Microsoft Store, и вы хотите:

- держать рабочий и личный аккаунты Claude открытыми одновременно;
- работать с одной папкой проекта с разных аккаунтов;
- использовать общие MCP-серверы, настройки и историю Claude Code;
- чтобы ссылка входа из письма не открывалась в чужом окне Claude.

**Лучше поискать другое**, если вам нужно:

- **macOS:** этот лаунчер работает только на Windows. Посмотрите [claude-multiprofile](https://github.com/jmdarre-v/claude-multiprofile).
- **Полная изоляция аккаунтов:** общий доступ здесь включён по умолчанию. Его можно выключить, но инструмент, построенный вокруг изоляции, подойдёт лучше.
- **Claude Code только в терминале:** для этого лаунчер для десктопа не нужен.

## Возможности

- **Отдельные входы.** Каждая копия Claude Desktop хранит свою сессию, поэтому все аккаунты остаются в системе одновременно.
- **Вход по почте попадает в нужную копию.** Ссылка из письма открывается в копии, которая её ждёт, а не в основном Claude.
- **Одна рабочая папка.** Один проект можно открывать с разных аккаунтов.
- **Общие настройки и MCP.** При запуске копия берёт MCP-серверы и настройки из основного Claude. Это можно выключить.
- **Общая история Claude Code.** Все копии видят одни и те же сессии Code. Это можно выключить.
- **Ярлыки на рабочий стол** для каждого аккаунта.
- **Интерфейс на русском, английском и китайском.** Лаунчер берёт язык из Windows.
- **Основной Claude остаётся как был.** Он работает как обычно, а его данные читаются или становятся общими, только если включены настройки общего доступа.

## Установка

**Нужно:** Windows 10 или 11 и [Claude Desktop](https://claude.ai/download) из Microsoft Store.

В PowerShell:

```powershell
curl.exe -L -o "$env:TEMP\ClaudeMulti.zip" https://github.com/Markwork51020/claude-desktop-multi-account/releases/latest/download/ClaudeMulti-win32-x64.zip
```

```powershell
Expand-Archive "$env:TEMP\ClaudeMulti.zip" "$env:LOCALAPPDATA\Programs" -Force
```

```powershell
Start-Process "$env:LOCALAPPDATA\Programs\ClaudeMulti-win32-x64\ClaudeMulti.exe"
```

Или скачайте zip из раздела [Releases](https://github.com/Markwork51020/claude-desktop-multi-account/releases/latest), распакуйте и запустите `ClaudeMulti.exe`.

Сборка не подписана, поэтому Windows SmartScreen может предупредить о риске: нажмите **Подробнее → Выполнить в любом случае** или [соберите приложение из исходников](#сборка-из-исходников). В каждом релизе указан SHA-256 архива.

## Как добавить аккаунт

1. Нажмите **+ Добавить аккаунт** и введите название. Откроется отдельное окно Claude с пустым входом.
2. Войдите по почте и откройте ссылку из письма.
3. В первый раз Windows спросит, чем открыть ссылку. Выберите **Claude Multi** и отметьте **Всегда использовать это приложение**.

Ссылка попадает в ту копию, которую вы открыли последней из ждущих входа. Чтобы заново войти в уже существующую копию, сначала выберите **⋯ → Войти заново**.

## Частые вопросы

### Как сделать мультиаккаунт Claude или открыть второй аккаунт на одном компьютере?

Установите Claude Multi и нажмите **+ Добавить аккаунт**. Откроется ещё одна копия Claude Desktop со своим входом, а основной аккаунт останется открытым.

### Можно ли использовать два аккаунта в Claude Desktop одновременно?

Само приложение этого не умеет: оно работает с одним аккаунтом за раз, а для переключения обычно приходится выходить. Claude Multi обходит это так: для каждого аккаунта он запускает отдельную копию официального приложения.

### Как запустить две копии Claude Desktop на Windows?

Запускайте приложение с разным `--user-data-dir` для каждой копии:

```powershell
& "$env:LOCALAPPDATA\Microsoft\WindowsApps\claude-desktop.exe" --user-data-dir="$env:USERPROFILE\.claude-work"
```

Claude Multi делает то же самое. Для второго окна хватит и ярлыка, но останется проблема со входом, описанная ниже.

### Почему ссылка входа из письма открывает не тот аккаунт?

Ссылка работает через протокол `claude://`, и Windows передаёт её основному Claude, поэтому вторая копия её не получает. Claude Multi регистрируется как обработчик таких ссылок и передаёт каждую той копии, которая ждёт входа.

### Ярлык или Claude Multi?

| | Ярлык с `--user-data-dir` | Claude Multi |
| --- | --- | --- |
| Второе окно со своими данными | Да | Да |
| Ссылка из письма открывается в нужном окне | Нет | Да |
| Список аккаунтов | Нет | Да |
| Общие MCP и настройки | Вручную | Встроено, можно выключить |
| Общая история Claude Code | Вручную | Встроено, можно выключить |

### Работает ли Claude Code в каждой копии?

Да. Каждая копия — полное приложение, поэтому вкладка Code работает под аккаунтом этой копии. Все копии могут работать в одной папке.

### Это песочница?

Нет. Каждая копия — то же самое приложение, только с другой папкой данных. Входы и данные приложения разделены, но все копии работают с правами вашего пользователя Windows и видят одни и те же файлы. Не считайте это защитой или изоляцией.

### Работает ли это с версией из Microsoft Store?

Да, и пока поддерживается только она. Данные лежат в `%USERPROFILE%\.claude-multi`, чтобы не попасть в виртуализированную папку AppData приложения из Store.

### На каком языке интерфейс?

Лаунчер берёт язык из Windows: русский, английский или упрощённый китайский, для остальных языков — английский. На язык самого Claude Desktop это не влияет.

### Даёт ли он доступ к Claude там, где сервис не поддерживается?

Нет. Он не даёт ни аккаунтов, ни сетевого подключения, ни доступа к Claude и не обходит региональные ограничения. Проверьте [список поддерживаемых регионов](https://www.anthropic.com/supported-countries) Anthropic.

### Меняет ли он Claude Desktop и отправляет ли куда-то мои данные?

Нет. Подробнее в разделе [Как это работает](#как-это-работает).

### Это разрешено?

Зависит от вашего тарифа и способа использования. На каждый аккаунт действуют условия Anthropic, и этот проект не может ответить за вас. Прочитайте их, особенно если собираетесь обходить лимиты дополнительными аккаунтами.

## Как это работает

Claude Multi запускает официальное приложение со своим `--user-data-dir` для каждого аккаунта, поэтому у каждой копии свой вход и свои данные. Он не меняет файлы Claude Desktop, и своего сервера у него нет. Ссылки входа сразу передаются копии, они нигде не сохраняются и не пишутся в логи. Если общие настройки включены, конфиг MCP вместе с секретами в нём копируется в каждый профиль на вашем компьютере.

| Что | Где |
| --- | --- |
| Аккаунты и профили | `%USERPROFILE%\.claude-multi` |
| Обработчик ссылок (только для текущего пользователя) | `HKCU\Software\Classes\ClaudeMulti.Link`, `HKCU\Software\ClaudeMulti` |
| Регистрация приложения (только для текущего пользователя) | значение `Claude Multi` в `HKCU\Software\RegisteredApplications` |

Общая история сделана через связь каталогов (junction): папка сессий каждой копии указывает на основную.

## Ограничения

- **Ранняя версия.** Пока проверено на одном компьютере: Windows 10 и версия из Microsoft Store. Если ссылка попала не в то окно, [создайте issue](https://github.com/Markwork51020/claude-desktop-multi-account/issues).
- **Только Windows** и пока только версия Claude Desktop из Microsoft Store.
- **Не открывайте одну сессию Code в двух копиях одновременно.** Они пишут в одни и те же файлы.
- **Вход в коннекторы.** Ответы OAuth для MCP-коннекторов, запущенных из копии, приходят в основной Claude.
- **Вход через Google и SSO.** Такие ссылки перенаправляются так же, но это не проверялось.
- **Cowork.** Пользователи схем с `--user-data-dir` сообщают, что Cowork может работать только в одном профиле за раз. Здесь это не проверялось.
- **Обновления Claude Desktop могут что-то сломать.** Лаунчер опирается на текущее поведение приложения, а не на поддерживаемый API.

## Удаление

1. Удалите папку приложения. Если хотите стереть входы и данные копий, удалите ещё `%USERPROFILE%\.claude-multi`.
2. Удалите записи реестра:

```bash
reg delete "HKCU\Software\Classes\ClaudeMulti.Link" /f
```

```bash
reg delete "HKCU\Software\ClaudeMulti" /f
```

```bash
reg delete "HKCU\Software\RegisteredApplications" /v "Claude Multi" /f
```
